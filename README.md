> *"Studying the masters of the past, engineering with the relentless aerodynamic precision of Formula 1, and wielding code as both science and sovereign art."*

A bespoke, high-performance personal portfolio engineered with the **Latverian Dark Mode (Doctor Doom)** aesthetic. It synthesizes ruthless scientific authority, Formula 1 aerodynamic discipline, and arcane-cybernetic micro-interactions.

---

## 🏛️ Design System Architecture

### 1. Latverian Dark Mode Color Palette
| Token | Hex | Role | Visual Concept |
| :--- | :--- | :--- | :--- |
| **Matte Obsidian Black** | `#0a0a0a` | Background Base | Deep, minimalist substrate that eliminates eye strain and focuses contrast. |
| **Latverian Emerald** | `#1B4D3E` | Primary Accent | Rich dark forest green for footer blocks, accents, and hero plates (Doom's cloak). |
| **Brushed Titanium** | `#878681` | Secondary Accent | Metallic cool grey for 1px borders, precision lines, and armor framing. |
| **Mystic Neon Green** | `#39FF14` | Highlight & Glow | Sparingly used for active states, brackets `[ ]`, slashes `/`, and telemetry indicators. |

### 2. Typography of Intellect & Authority
- **Headings**: `Oswald` / `Syne` — Architectural, imposing, uppercase with wide letter tracking.
- **Body & Telemetry**: `JetBrains Mono` / `Space Mono` — Clean monospace grounding the site in a high-security terminal and scientific laboratory environment.
- **Syntactical Accents**: Mystic Neon Green (`#39FF14`) exclusively reserved for brackets `[ ]`, slashes `/`, and key data metrics.

### 3. UI Textures & Geometry
- **Frosted Glass + Brushed Titanium**: Multi-layered frosted glass panels (`backdrop-filter: blur(14px)`) bordered by 1px titanium lines and neon corner brackets.
- **Circuit-Runes Canvas**: Interactive HTML5 Canvas line art. Rigid, angular circuit board traces on the left organically morph into concentric, glowing magical sigils and pentagram geometry on the right.
- **Procedural Carbon Fiber**: Twill weave CSS pattern woven into project cards and hover states, reflecting Formula 1 aerodynamic composite engineering.
- **Sharp Brutalist Geometry**: Chamfered 45-degree corner polygons (`clip-path`) across cards, buttons, and HUD badges.

## ⚡ Interactive Features & Micro-Interactions

1. **Latverian Loading Screen**:
   - Precision mechanical gear continuously turning inside an arcane pentagram with glowing vertex pulse nodes.
   - Live telemetry countdown ticker (`00%` to `100%`) with protocol synchronization logs.
2. **Minimalist HUD Crosshair Cursor**:
   - Custom crosshair with four reticle lines, coordinate telemetry readout `[X:Y]`, and smooth trailing physics.
   - Dynamic spark generation along titanium card borders upon hovering.
3. **Audio Synthesizer (Zero-Asset Web Audio API)**:
   - Built-in sound effects engine generating tactile tactical clicks and glitch noises on project interaction.
   - Toggleable via the `[SFX: MUTED / ACTIVE]` button in the top HUD.
4. **Blueprint Inspector Modal**:
   - Detailed architectural breakdown for projects with ASCII system flowcharts, latency specs, and tech stack pills.
5. **Interactive Diplomatic Uplink**:
   - Encrypted transmission terminal with simulated 4096-bit cipher encryption logs and diplomatic dispatch confirmation.
6. **Live Telemetry Bar**:
   - Real-time Latveria standard time telemetry (UTC milliseconds) updated in the HUD.
